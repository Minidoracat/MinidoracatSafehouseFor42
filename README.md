# Minidoracat Safehouse

多人專用伺服器的安全屋系統：用地契自訂安全屋範圍，自動避開道路與資源點，分享給玩家或陣營並逐項授權。

Project Zomboid Build 42 MOD。

## 發布狀態

已發布到 Steam Workshop（連結見「安裝」）。

## 功能

- **分級地契**：8 種地契物品（1–8 級），各有自己的圖示（等級色封蠟上印著等級數字），管理員啟用前幾級（預設 3 級），每級各自設定最大面積（格數）、外框上限，以及每位玩家有幾個免費、可買、可租名額。以格數為主：預設 1–8 級依序是 576（24 × 24）、1,024（32 × 32）、1,600（40 × 40）、2,304（48 × 48）、3,136（56 × 56）、4,096（64 × 64）、6,400（80 × 80）、9,216 格（96 × 96），範圍可以拼成任何形狀；外框（包住整間的矩形）預設放寬到同面積正方形邊長的 2 倍：48、64、80，4 級起 96，任何等級最大 96 × 96。1 級大約是一棟房子連院子；城鎮的路把地切得很碎，3 級以上的大範圍多半要在鄉間才圈得出來。面板與地契說明在格數旁邊寫出相當於幾乘幾。也可以切成「免費」模式，不用地契就能建，名額照 1 級算。
- **地契取得**：可以製作（每級可設不開放／寬鬆／標準／嚴格，預設只有 1 級開放、標準難度）；製作清單只列開放的那一種難度（原版製作視窗與 Neat Crafting 都一樣），管理員改難度後開著的製作視窗立刻換成新的那一條。管理員可以用原版 `/additem` 發給玩家；有 Economy 時管理員可以把地契上架到商店。也可以讓地契從辦公桌、檔案櫃與保險箱掉出來：預設關閉，管理員打開「地契掉落」後照各級機率掉落（預設 1 級 1%、2 級 0.3%、3 級 0.1%，之後每級約再除以 3，8 級 0.001%）。地契物品說明會顯示該級的大小上限與是否啟用。
- **自訂範圍**：用滑鼠拖曳（手把用十字鍵逐格）或走到兩個角落框出一塊，照〔加入〕／〔挖掉〕模式加進範圍或挖掉，滑鼠點一下是一格；一間預設最多 4 塊（管理員可調 1–8），可以拼成 L 形、U 形等形狀，各塊要連成一片、不能圍出空洞，總面積與外框照地契上限。框選的範圍用青色染在地板上（人物照常站在上面，不會被蓋住；高草叢本身不變色，只染到草底下的地面）。框選時面板即時顯示外框、面積、塊數與這張地契的上限，超過或形狀不合規則時字和地面範圍都變紅；隨時可以〔復原〕〔清除〕，預檢頁按〔修改範圍〕回到編輯、範圍保留。確認時要站在範圍裡。伺服器在送出當下重新檢查全部規則，預檢頁逐條寫出沒過的原因與怎麼改，地面上同時標紅壓到的道路格、資源建築或別人的安全屋。
- **建立後可以重新框選**：建立後 30 分鐘內（可設定，0＝關閉）可以從現有的形狀改起、重畫範圍，不另扣地契；每間最多重畫 5 次（可設定 1–20）。管理視窗的按鈕會顯示剩下的時間與次數。放棄安全屋不退地契。
- **閒置收回**：屋主或分享名單上的人（含陣營分享的成員）走進安全屋範圍，就會重新計時；超過 14 天都沒有人回來，安全屋會自動收回，地契不退。買斷名額保護的安全屋是 30 天；租用名額保護的不會因此收回，照租期處理。伺服器關機、或沒人在線而暫停的時間不算。管理視窗會顯示還剩多久，滑鼠移上去可以看說明。天數由管理員設定，0＝不收回。
- **保險**（需要 Economy）：暫時不能上線的玩家可以花錢延長保留時間，天數自己選，每天的價格由管理員逐級設定。保險期間不會被收回，保險結束後才重新倒數。預設不販售。
- **自己的安全屋可以相鄰**：同一位屋主的安全屋只禁止重疊，可以緊貼；屋主和你同一個陣營的，預設也可以緊貼（管理員可設「與同陣營間距」）；和別人的安全屋要保持間距（預設 2 格；太近時預檢會寫出至少要隔幾格，跟著伺服器設定）。陣營看建立或重新框選當下的。
- **避開道路**：伺服器逐格看地面，預設主要道路與「街道與停車場」都不能圈；住宅與它的獨立車庫、工具間周圍幾格內只有主要道路算路，讓玩家能圈住自家車道。原版建築房間裡的地面不算路（有些住宅的車庫鋪的是道路柏油）；玩家自己圍出來的房間照樣看地面。類別與安全邊界由管理員調整。
- **避開資源點**（需要 MiniMap）：軍事、警察、槍店、醫療、藥局、消防、加油站、監獄等建築整棟不能圈；管理員可選「小地圖資源」（和玩家在小地圖看到的一致）或「房間資料」（也涵蓋其他地圖 MOD 的建築，較嚴），並勾選類別。
- **禁建區**：管理員在管理員面板的排除頁按〔管理禁建區〕，開到畫面右側的禁建區視窗，按〔新增禁建區〕框出不能建立安全屋的地方（例如道路判定抓不到的土路、原版通往軍事基地的必經路），框法和建立安全屋一樣（拖曳或走到兩角，可以加入、挖掉拼成多塊），每個取一個名稱，最多 100 個。禁建區視窗可以搜尋名稱、看每個禁建區的座標，按〔傳送〕到它的中央（要有傳送到座標的權限）；視窗開著時地上用亮紅色畫出禁建區，傳送過去的那個用黃色。玩家也看得到：「在地面顯示範圍」的「禁建區」那類（預設開）用同一個亮紅色畫出附近的禁建區，管理員新增、刪除後在線的玩家馬上跟著更新。玩家建立或重新框選時範圍壓到禁建區就不能建立，預檢會在地上標紅壓到的部分並寫出禁建區的名稱；只貼著邊不算壓到。管理員自己建立也一樣擋。已經建好的安全屋不受影響：禁建區視窗會在每個禁建區底下列出壓到它的安全屋，要不要處理由管理員決定。
- **分享**：分享給指定玩家或屋主所在的陣營，逐項授權：成員（進出與拿放容器）、用電器（含取水、發電機的接線、開關、加油與修理）、搬家具（含搬走發電機）、建造（含拆除）、農耕、遠距拿取（伺服器開放「可以遠距拿」時，站在安全屋裡把別處容器的東西直接拿進背包）、邀請（可以把還不能進屋的玩家加進來，只能給出自己也有的權限，不能改或移除既有成員）、管理（可以替屋主改權限、停止分享與邀請，但只能加減自己也有的權限、不能再給管理；對方其他的權限照留）。邀請與管理只能給個別玩家，陣營分享最多到遠距拿取。輸入玩家名稱時下拉列出候選：線上玩家與你分享過的人（不分大小寫比對名字的一部分）；離線的玩家要打完整名字（分大小寫）才會出現，不能用關鍵字列出全服玩家。新加的人要是伺服器認得的玩家：在線上、Steam 伺服器上裝了本 MOD 之後登入過、管理員設過個人的 1 級免費名額，或已經是某間安全屋的屋主或成員；非 Steam 伺服器沒有登入紀錄，對方要在線上或已經和某間安全屋有關。改既有成員：點名單上那一列就帶入他現在的權限，〔儲存變更〕只改點過的；名單可以一次選好幾位（勾選框、按住 Ctrl 或 Shift 點、Ctrl+A；Esc 或〔清除選取〕取消；手把用 A 勾選、B 取消），選兩位以上時每個權限寫出幾位有，點一下依序是加給全部、從全部拿掉、不改，〔套用到 N 位...〕先列出要改給誰再確認。停止分享（一位或好幾位，以及陣營的〔停止〕）都先確認。打名單上的人的名字按〔分享給玩家〕，會選到他那一列、不會蓋掉他的權限。陣營解散、換領袖或屋主離開陣營時，陣營分享自動暫停並移除只靠陣營進來的人，屋主一鍵恢復。每間分享人數上限預設 8（管理員可調 0–32）。
- **安全屋管理視窗**：從 User Panel 的「安全屋管理」按鈕或家族工具列開啟，分「我的安全屋」與「分享給我的」；可改名、看狀態與土地規則、管理分享、放棄。清單底下的「在地面顯示範圍」（預設開）在地上畫出附近的安全屋與禁建區，分五類、各一種顏色：我的（青）、分享給我的（藍）、同陣營的（橘）、其他玩家的（洋紅）、禁建區（亮紅），草地、柏油上都是同一個顏色，開關旁的色塊就是地上看到的顏色。平常只畫邊緣；勾〔整片顯示〕（預設關）時整片塗上較暗的顏色、邊緣用較亮的顏色。安全屋和禁建區重疊的地方顯示安全屋的顏色。人物站的地方附近、會被房子擋住的那幾格改成染在地板上（人物照常站在上面、房子照常擋住它），顏色比較深；每類可以分開關；關掉視窗、下次進遊戲都照樣顯示（選項的「模組」頁也能切換）。同陣營的、其他玩家的要伺服器開放（預設只開同陣營的）。按〔建立安全屋〕或〔重新框選〕時管理視窗先收起來、只留建立面板，關掉建立面板後再回來，建立成功時直接停在新的那間。安全屋再多，清單也只是捲動，「在地面顯示範圍」的開關固定在清單底下；視窗縮得太小或字型放大時，視窗會自己長高到放得下。原版的建立安全屋右鍵選項會拿掉，原版安全屋視窗遇到本 MOD 的安全屋會改開管理視窗。
- **安全屋重生點**：玩家站在自己有權限的安全屋裡（屋主或成員都可以），在管理視窗按〔設為重生點〕，之後死亡、重新開始的新角色一律出現在設定時站的那一格，不論出生選單選哪裡（同一次連線中死亡時不會出現出生地點選單：只有一個地點時原版直接跳過）。在樓上或地下室設的點，伺服器當下確認不了那層地板還在時（那一帶沒有載入，或地板拆掉、燒掉了），改出生在同一格的地面層。每人一個重生點，換一間設就取代舊的，也可以〔清除重生點〕。安全屋被放棄或停用、玩家被移出成員時暫時失效，照原版方式出生，恢復後又能用。總開關是原版伺服器設定 `SafehouseAllowRespawn`（關著時不能設、也不套用）。原版「在安全屋重生」的勾選，在更新後第一次開機自動換成那間安全屋中央的重生點，之後不再使用原版勾選。分割畫面的第 2–4 位玩家重生時也會落在主帳號的重生點。
- **室內檢查**：在地上按右鍵選「檢查這裡算不算室內」（查點到的那格），或在管理視窗按〔室內檢查〕（查站的那格），判斷自己蓋的房子在多人伺服器上算不算室內（保暖、擋風、體溫照室內算）。判定照伺服器算體溫的規則：四面要圍起來（牆、門框、窗框、圍籬都算，裝在門框裡的門開著、玻璃拆了也算；住宅的車庫門開著時不算，關上才算；同一格有柱子時，那一格西側的牆不算），而且每一格正上方那一層都要有地板；缺一格屋頂，整個房間就照室外算。不算室內時列出缺幾格牆、缺幾格屋頂、離你多遠（缺口上有門時寫「開著的門」或「不算牆的門」，那格有柱子時寫「有柱子的牆」，都不叫你補牆），並在地上標出位置（這次檢查到的範圍地板稍微變暗、缺屋頂的格子地板染紅、缺牆的地方畫一面亮紅色的牆，可以關掉）。「不算牆的門」是關著也不算牆的門（例如閘門、兩層樓高的大門），要在門內加一道牆或門框。蓋牆時遊戲自動補的牆角和牆疊在同一格時，伺服器會拆掉那根牆角（蓋上牆時，或在那裡做室內檢查時）；自己蓋的柱子不會被拆，要自己拆。遊戲不會隨時重新判斷門：用原版右鍵選單開關門時，遊戲記的還是上次判斷時的樣子（例如門被 Knox Pass 打開、再用右鍵關上，遊戲照樣當成缺口）。做室內檢查時，伺服器發現門關著、遊戲卻還當成缺口，會當場請遊戲重算那幾格：面板先寫「紀錄過期的門」，一秒多後自己再查一次；反過來的情況（門用右鍵打開，遊戲還當成牆）不會改，房間照樣算室內。同一棟的其他房間也一起列出：同一層沿著相連的屋頂找，樓上樓下沿著樓板找，每一層都分析，有不只一層時前面寫第幾樓；點一下就換看那一間，地上的標示跟著換到那一層。單層房子屋頂上的平台（上面沒再蓋一層）不算一層。比牆多一圈的屋頂、門廊這類只有屋頂的地方標成「屋簷下」，不列缺口。面板開著時，附近的牆或地板有變動就自己重新檢查；關掉面板後完全不在背景檢查。只能查自己附近 40 格內，每位玩家每秒最多一次；一棟最多列 12 間，太大的建築只檢查離查的位置最近的一部分；地圖原有的建築照原版規則算室內，自己在地下蓋的房間遊戲永遠不算室內。
- **物品搜尋**：管理視窗安全屋名稱旁的〔搜尋物品〕列出這間安全屋裡所有容器的東西：家具容器、容器裡的背包（往裡看一層）、地上的物品、停在範圍內的車；同名的併成一列，可以搜尋名稱、依分類與樓層篩選、依名稱、數量或距離排序。搜尋框右邊的〔清單｜網格〕可以切成圖示網格（一個物品一格，寫件數、在幾個地方或第幾樓、離你幾格；名稱截掉時滑鼠移上去看全文），會記住上次選的（第一次是清單，選項的「模組」頁也能改）。點一列（網格是點一格）看它放在哪些地方，選一處按〔指引我過去〕，畫面上有箭頭帶路（同一層時地上再畫一圈；在別層時箭頭換成上下樓的圖示），人物旁邊另有一個繞著人物轉、指向目標的箭頭（目標在畫面外時也看得到方向），走到旁邊時戰利品視窗自動切到那個容器；關掉面板也會繼續帶路，最多 10 分鐘。按〔自動走過去〕時角色會自己走到容器旁邊、箭頭照樣亮著（走法同原版點家具走過去：會上下樓、自己打開關著的門，不跑步、不繞開殭屍；車上的走到那個置物位置旁），遇到上鎖的門、關著的窗或沒有路時停下並寫出原因、箭頭留著，按方向鍵或取消就停。站在容器旁邊（和原版戰利品視窗列得出那個容器的距離一樣）時，不論管理員怎麼設都能按〔拿取...〕填要拿幾個（一次最多 50 個），照原版搬東西一件件拿進背包，走動就中斷；太遠時按鈕停用並寫「走到容器旁邊才能拿。」，放在容器裡的背包要先把背包拿出來。搜尋與帶路都在自己的遊戲裡做、不問伺服器，面板關著時什麼都不做；只列得出自己這台電腦載入的地方（玩家四周約 50–80 格，畫面越大越遠），太遠沒載入的面板會寫出有幾格。上了鎖的容器（密碼鎖，或掛鎖而身上沒有鑰匙）和鎖著的車不列、也不能遠距拿，面板只寫有幾個。管理員可以設成「可以遠距拿」：站在安全屋任一塊裡（管理員可以用「安全屋外的範圍」放寬到安全屋外幾格內）、有「遠距拿取」權限的成員按〔拿取...〕選要拿幾個（一次最多 50 個），照原版搬東西的時間站著不動，就直接拿進背包，走開就中斷；背包放不下的留在原處。車上和人形模特兒身上的東西只能走過去，用戰利品視窗拿。預設「只指引」，也可以整個關掉。
- **車開不進去**：車上只要有人不能進那間安全屋（包括坐乘客座的人；拖著的拖車也算），車子開到邊界前就停下來，畫面提示是誰不能進（你自己或車上的人）。原本就停在範圍裡的車可以往外開走，只是不能再往裡開。屋主、分享名單上的人和管理員照常開進去；每一間安全屋都適用，包括不是本 MOD 建的。
- **伺服器權威**：建立、放棄、分享、名額都由伺服器判定；有人用原版封包改本 MOD 安全屋的屋主、名稱或成員時，伺服器每輪把它改回來；被刪掉的安全屋自動重建。
- **名額**：每個地契等級各設三個數字：每位玩家免費幾間、最多買斷幾個名額、最多同時租幾個名額，這一級每人最多幾間＝三者相加；預設只有 1 級免費 1 間。買斷與月租需要 Economy，價格由管理員逐級設定。
- **管理員面板**：六頁（規則、地契、排除、玩家、原版安全屋、付費），改完按「套用變更」立即寫回伺服器沙盒設定並同步給線上玩家。

## 伺服器設定（必要）

本 MOD 不會自己改伺服器設定。下列原版選項任一不符時，伺服器進入「伺服器設定不完整」：停止新建、分享等操作，但既有安全屋的保護、成員同步與管理員處理照常，線上管理員會收到提示。

管理員面板「規則」頁把不符的選項排成「設定｜目前值｜建議值｜原因」表。帳號能修改伺服器設定的管理員可以按〔修正伺服器設定〕一次改好必要的設定，建議的設定每列有〔套用〕可以逐項改（`SaveWorldEveryMinutes` 送 10；`ChatStreams` 只拿掉 `sh`、其他頻道照舊）；確認後用遊戲的 `/changeoption` 改好並 `/reloadoptions` 讓所有玩家生效，和原版「檢視伺服器設定」逐項修改一樣：伺服器會用目前生效的值重寫設定檔，伺服器執行中直接改過、還沒重新載入的設定檔內容會被蓋掉。

| 選項 | 必須 | 原因 |
|---|---|---|
| `PlayerSafehouse` | `false` | 原版建立安全屋不經過任何 MOD 檢查，地契、名額、道路、資源點都管不到 |
| `AdminSafehouse` | `false` | 同上（建築物安全屋的路徑） |
| `SafeHouseRemovalTime` | `0` | 原版會刪掉太久（真實時間的小時數）沒有成員回去的安全屋 |
| `War` | `false` | 原版戰爭模式會刪掉安全屋 |
| `SafehouseAllowTrepass` | `false` | 非成員要被趕出安全屋 |
| `SafehouseAllowLoot` | `false` | 非成員不能拿安全屋裡的東西 |
| `SafehouseAllowFire` | `false` | 安全屋裡不能放火 |
| `DisableSafehouseWhenOwnerConnected` | `false` | 屋主在線時保護不能關掉 |
| `AntiCheatSafeHouse` | `1`、`2` 或 `3`（建議 `3`＝只記錄） | `4` 會關掉原版對安全屋封包的檢查 |

另外，原版的「建立安全屋前要存活的天數」（`SafehouseDaySurvivedToClaim`）照常適用。

**建議**（不符時管理員面板會顯示提醒，不會停用功能）：

- `SaveWorldEveryMinutes` 設 10–15。`0`（原版預設）或大於 30 時，伺服器崩潰會讓上次世界存檔之後的分享、改名、放棄都回到存檔時的樣子（剛建好的安全屋會在重開時自動補回，見「已知限制」）：安全屋跟著世界存檔，玩家背包大約每 3 分鐘就自己存一次。
- `AllowCoop=false`：擋掉分割畫面玩家自己輸入名字冒用別人的路徑。
- `ChatStreams` 拿掉 `sh`：原版安全屋聊天的成員名單不會跟著本 MOD 的分享更新。陣營改用 `/faction` 聊天。

伺服器關機請用 `quit`（或會送 `quit` 的管理工具），不要直接結束程序。

**每間最多塊數調高前先看這裡**：每一塊在遊戲裡都是一間獨立的原版安全屋，所以塊數上限越高：玩家登入時要下載的安全屋資料越多；全服共用的成員名單容量（每一塊各算一次）用得越快，用完就不能再建立或分享；形狀複雜時，玩家每改一次框選範圍都可能短暫卡頓；被移出的成員越可能先落在同一間的另一塊、多等一輪檢查才出去。調低只影響之後的建立與重新框選，已建好的安全屋不受影響。同樣的說明也寫在沙盒選項的提示與管理員面板規則頁。

**從 `Mods=` 拿掉本 MOD 會清掉這個分頁的設定**：下次開服沙盒檔裡本 MOD 的整段會被刪除，加回來時回到預設值。暫時移除或退版前，先備份伺服器的 `<伺服器名>_SandboxVars.lua`。

## 管理員面板

需要原版「設定安全屋」權限（`CanSetupSafehouses`）的角色才能開。

- **規則**：建立方式、間距、每間最多塊數、分享上限、保留天數、閒置收回天數與保險開關、陣營分享、重新框選的時限與次數、玩家在地面看得到哪些別人的安全屋、物品搜尋（關閉／只指引／可以遠距拿，以及遠距拿取可以站在安全屋外幾格內；只在選「可以遠距拿」時能改）；也顯示伺服器設定狀態、接管舊安全屋的結果，以及處理異常安全屋（重新綁定屋主或釋出）。
- **地契**：只列啟用的等級，表格底下〔新增第 N 級〕〔移除第 N 級〕（最多 8 級，按〔套用變更〕才生效）；地契掉落總開關（關著時掉落欄反灰）；各級最大面積（旁邊寫出相當於幾乘幾，打字時跟著變）、外框上限、掉落機率、製作難度（滑鼠移到「製作」格可預覽配方），以及名額三欄「免費」「可買」「可租」（填數字），「每人最多」欄自動顯示三者相加。有支援的 Economy 時多一顆「到經濟中心上架」。
- **排除**：道路、安全邊界與類別；資源點的判定方式與類別（沒有 MiniMap 時藏起來，寫明要裝小地圖 MOD 才有這個功能）；禁建區個數與〔管理禁建區〕（清單、搜尋、〔傳送〕、新增、刪除與壓到各禁建區的安全屋在另開的禁建區視窗）。
- **玩家**：伺服器分頁搜尋（每頁 50 位），可以按〔1 級免費名額...〕替個別玩家改 1 級的免費名額（只改 1 級；留空＝用全服預設）、查看、代為放棄（會寫稽核記錄）。
- **原版安全屋**：不歸本 MOD 管的原版安全屋（接管時留下的，或裝好本 MOD 之後才出現的），每間可以〔傳送〕過去看或〔釋出...〕；詳見下面「從 Better Safehouse 或原版安全屋接手」。
- **付費**（Economy 可用時）：逐級設定買斷價、每期租金與保險每日價（只列啟用的等級），以及共用的幣別、租期、寬限、提醒與自動續租。每人能買、租幾個不在這頁設，頁面上寫著「要不要販售、每人能買或租幾個，看「地契」頁的可買、可租。」

原版管理員指令 `/releasesafehouse`、`/addusertosafehouse`、`/kickuserfromsafehouse` 以安全屋名稱找第一間符合的，名稱重複時會打到別間；用它加進本 MOD 安全屋的人也會在下一輪被移除。本 MOD 的安全屋一律從管理員面板處理。

原版管理員面板的「安全屋清單」也列出本 MOD 的安全屋：寫真正的屋主與成員人數，後面標淡色的「（本 MOD）」，分成多塊的每塊一列並寫第幾塊。選別人的本 MOD 安全屋按〔檢視〕，會開本 MOD 管理員面板的「玩家」頁並展開那位屋主；自己的照舊開管理視窗。

## 付費名額（選用 Economy）

- 每一級各有免費、可買、可租三個數字。免費名額用完後，每多一間要一個該地契等級的付費名額：買斷，或按月租用（每期 30 天）；每位玩家最多買斷到「可買」、同時租用到「可租」的數字。預設價格 1 級月租 100、2 級 300、3 級起 700，買斷為月租的 12 倍；預設不販售，管理員在地契頁把各級的「可買」「可租」設成 1 以上才開賣。調低只擋新的購買，已經買、租的名額照常使用與續租。
- 名額不夠、這一級還能買或租時，建立面板會顯示〔前往付費〕並預選該等級；可買、可租都到上限時，預檢改寫「你在這一級的安全屋已達每人上限。」。名額視窗每一級寫出已有幾間、最多幾間，以及免費、買斷、租用各用了幾個與上限；還有空的付費名額時寫還能再建幾間。〔買斷〕〔租用〕到上限時停用，底下寫「已達這一級的上限，不能再買或再租。」；伺服器沒開放任何名額時寫「這個伺服器沒有開放任何名額。」。付款處理中與付款結果寫在按的那一級底下，付款有結果時另外跳通知。付款、續租、到期、建好或放棄安全屋、管理員改名額之後，開著的名額視窗與建立面板會自己更新，不用重開。
- **租約不綁定哪一間**：名額視窗展開租約時，最後一行寫「租約不綁定哪一間房子：租約到期時，如果這一級的付費名額少於用付費名額的安全屋，最新建的那間會先停用保護，補回名額後恢復。」
- **看每間用哪種名額**：管理視窗「我的安全屋」清單第二行在狀態後面標出名額種類：免費名額或付費名額（含等級），接管來的寫「遷移來的安全屋」。
- **租約到期**：寬限結束後該級仍超額時，該屋主那一級最新建的付費安全屋會「停用」（停用的間數不超過到期的名額數）：保護暫停、範圍保留 7 天（可設定），續租或補回名額就恢復；保留期滿才釋出。其他等級不受影響。退款或管理員調低數字（包括免費名額）造成的超額不停用，只是不能再建。
- **閒置收回與付費名額**：同一位屋主同一級有付費名額時，名額照數量保護那一級最久沒人回去的幾間：租用名額保護的不會因閒置收回，買斷名額保護的照 30 天（設得不比免費長時照免費），其餘照 14 天；同一級一次只收一間，收掉後名額改去保護剩下的。租約結束、退款、移除 Economy 或名額改去保護別間時，失去保護的那間從那時起有完整天數。讀不到 Economy 時，可能有付費名額保護的安全屋先不收回，讀不到的期間不算。管理員把天數改短時，從改的那時起至少還有新的天數。
- **保險**：管理員打開「閒置保險」後，屋主在管理視窗選天數付款，保險期間那一級的安全屋都不會被收回，保險結束後重新倒數。保險是一天一期的租約、不會自動續租、到期就結束；管理員退款會把這筆保險整筆收回。要用支援一次付多期的 Economy（API rev 7 以上）。
- **管理員移除地契等級**（地契頁〔移除第 N 級〕）：玩家手上那一級的地契不會消失，但不能用、不會掉落、也不能製作，加回這一級就能再用；已經建好的安全屋照常保護；那一級的付費名額不能再買新的，既有租約照樣在名額視窗續租或開關自動續租（名額視窗會列出這種已關閉、但你還有付費安全屋的等級）。
- Economy 從伺服器移除後，停用中的安全屋恢復保護，超額只擋新增；Economy 版本不支援或讀取失敗時維持原狀，不停用也不恢復。

## 從 Better Safehouse 或原版安全屋接手（伺服器管理員）

中途安裝本 MOD 時，存檔裡原有的安全屋（Better Safehouse、原版或其他 MOD 建的）會在開服時自動接管：玩家不必等，管理員也不必審核或改檔案。只有第一次啟動本 MOD 時存檔裡就有安全屋的伺服器會接管；之後才出現的原版安全屋不會被接管。

1. **一次重啟完成**：關服，備份整個存檔資料夾、伺服器設定檔與 `Zomboid/Logs`。設好上面的必要選項，從 `Mods=` 拿掉 Better Safehouse、加入本 MOD（排在 UI Library 之後），開服。
2. **開服時自動接管**：沒有問題的安全屋全部變成本 MOD 的安全屋，屋主、範圍、名稱與成員照舊，玩家一進服就能用。管理員面板「規則」頁的遷移狀態顯示「已完成」、已接管幾間與留在原版幾間；稽核記錄有一行 `MIGRATION_ADOPTED`。
3. **條件不符時先等**：必要的伺服器設定沒改好，或 Better Safehouse 還在模組清單時，伺服器先不接管，面板顯示「等待中」與原因；改好後下次開服自動接管。等待期間舊安全屋照原版保護。

接管後：

- 屋主、範圍、名稱照舊；原本的成員（含 Better Safehouse 的副管理者）變成一般分享對象，權限是成員、用電器、搬家具、建造、農耕（等同原版成員能做的事），沒有「邀請」與「管理」；屋主之後可以自己調整。
- 接管來的安全屋都算 1 級、先佔屋主的 1 級免費名額；超出免費名額的也全部保留、不需要付費名額，只是屋主再建 1 級時要等免費名額空出來或用付費名額。壓到道路或資源點的舊安全屋也保留。接管來的安全屋不能重新框選。
- 這些安全屋留在原地當原版安全屋，本 MOD 不管理也不自動刪除：範圍不合法、屋主名稱不合法、和另一間範圍或左上角相同、超過全服 256 間，或成員多到接管後會擠掉之後新建與分享的空間（依建立時間由舊到新接管，接管最多用掉一半的資料空間）。清單在 `Zomboid/Lua/MinidoracatSafehouse/<伺服器名>/migration-completion.txt` 的 `skip` 列。它們和裝好本 MOD 之後才出現的原版安全屋一樣不會到期：閒置收回不管它們，原版的到期刪除也因為 `SafeHouseRemovalTime` 必須是 0 而關著，所以不會自己消失。管理員面板的「原版安全屋」頁列出它們：屋主、成員人數、大小、座標、多久沒人進去（伺服器關著的時間也算，閒置收回不算）、接管時留下的原因，超過閒置收回天數的另外標出；每間可以〔傳送〕過去看，或〔釋出...〕拿掉那一間的保護（屋裡的東西留在原地）。最多列 20 間，最久沒人進去的在前。之後伺服器上多了原版安全屋時，在線管理員會收到提示。名稱超過 40 字的會截短。
- 原版或 Better Safehouse 的「在安全屋重生」勾選會換成本 MOD 的重生點（那間安全屋中央）；安全屋聊天不搬。
- Better Safehouse 存在世界資料裡的記錄不讀也不改。
- Better Safehouse 自己的地契物品（3.1.1 有 5 種）在它從 `Mods=` 拿掉後，第一次載入就會從玩家身上與容器裡消失，裝回來也找不回。要補償的話，由管理員改發本 MOD 的地契；切換前先公告。
- 接管後、世界存檔前伺服器當掉：下次開服自動補回，不必處理。真的對不上的會出現在管理員面板「規則」頁的「需要處理的安全屋」，按「重新綁定」或「釋出」。

**還原**：想放棄接管，關服後把存檔、伺服器設定檔、模組清單與 `Zomboid/Lua/MinidoracatSafehouse/<伺服器名>/` 一起還原成第 1 步的備份。

`migration-completion.txt` 要留著：當機補回會用到。

## 已知限制

- **殭屍仍可能在安全屋裡生成**：原版安全屋本來就不擋殭屍生成，本 MOD 也不擋。
- **保護沿用原版安全屋**：非成員被趕出、不能拿東西是原版的判定。伺服器擋得住原版客戶端，但改過的客戶端可能繞過部分只在客戶端判定的保護；分享的細項權限（用電器、搬家具、建造、農耕）只對原版客戶端可靠，和原版一樣。擋車也一樣：改過的客戶端可能把車開進去，這時伺服器會讓車上不能進的人下車並傳到屋外，車留在原地。
- **門窗不設權限**：按 E 開門、直接開關窗戶伺服器擋不住，成員以外的人能不能開門照原版。
- **「成員」的進出與拿放容器分不開**：原版拿放物品沒有可以攔的地方，所以不做「只能進出、不能拿東西」的訪客。
- **安全屋資料是公開的**：原版會把每間安全屋的範圍、屋主與成員名單送給每位登入的玩家，改過的客戶端看得到。
- **成員可以把自己移出安全屋**：成員用原版指令移除自己時會被傳送到屋外；名單下一輪會修回，但位置不會。
- **不做的事**：不擋殭屍、不做搬移或擴建（只有建立後的重新框選）、不做土地買賣、不做全服地圖瀏覽與傳送（只有管理員能在禁建區視窗用原版指令傳送到禁建區）、不保證原版安全屋聊天同步、不能在遊戲內新增地契種類。
- **閒置收回看到訪、不看上線**：只上線不回到安全屋，計時照樣往下走；站進範圍約 20 秒內才會重新計時。重新框選或被伺服器補建的那一塊會當成剛有人到訪。
- **伺服器崩潰**：上次世界存檔之後的變更會回到存檔時的樣子。剛建好的安全屋例外：重開時自動補回，範圍、名稱、等級照建立時，之後加的分享要重新設定；放棄過的不會補回。建好後 3 分半內就當機的，玩家背包可能還沒存、地契可能已經回到屋主身上，這種會列在管理員面板「規則」頁的「需要處理的安全屋」（標示 `CRASH_UNCONFIRMED`）：先問屋主，地契還在就〔釋出〕，不在就〔重新綁定〕給原屋主。
- **玩家身分**：Steam 伺服器上，玩家上線時伺服器會自動把帳號名稱綁到當時登入的 Steam 帳號（建角、建立安全屋時也會綁），之後 Steam 帳號不符就不能管理。綁定前會檢查改名跡象（同一個 Steam 帳號剛用別的名字建過角色、或同一個位置的前一個角色剛死又換了名字），有跡象就不綁定。裝了本 MOD 之後還沒上線過的名稱，在本人上線前照名稱判定；改過的客戶端可能搶先冒用這種名稱。原版陣營與安全屋名單以名稱判定，分割畫面玩家可以自己輸入別人的名稱，建議關閉 `AllowCoop`；no-steam 伺服器不防重生改名。玩家換了 Steam 帳號會被當成別人，目前沒有解除綁定的功能。
- **多塊的安全屋**：每塊各是一個原生安全屋。被移出的玩家可能先落在同一間的另一塊，約 20 秒內會再被移出；塊數上限調得越高越常發生。
- **全服上限**：最多 256 間（含接管來的）。
- **物品搜尋看得到的範圍**：地上背包裡的東西、屍體與玩家身上的東西不列，容器裡的背包只往裡看一層。原版本來就把玩家附近容器的內容送給每位玩家（不用打開也一樣），所以搜尋沒有多洩漏什麼；改過的客戶端本來就看得到。

## 移除本 MOD 前

- 地契物品在移除後的第一次載入就消失，裝回來也找不回。
- 已建的安全屋會留在世界上，成員照原版受保護，也能用原版〔退出安全屋〕離開；但沒有人能再從遊戲內管理（屋主是本 MOD 的服務帳號），只能用原版管理員工具處理。之後若把 `SafeHouseRemovalTime` 改成非 0，超過那麼多小時（真實時間）都沒有成員進屋的安全屋會被原版刪掉。
- 先備份 `<伺服器名>_SandboxVars.lua`（見上面「規則與預設值」）。

## 資料存在哪裡（伺服器）

| 內容 | 位置 |
|---|---|
| 安全屋清單（範圍、屋主、分享、狀態） | 世界存檔的 `global_mod_data.bin`（公開讀取：不放 Steam 帳號與私人資料） |

### 發布到 Workshop

雙擊 `Publish_Workshop.bat`：先確認 Steam 用戶端已以作者帳號登入（未登入會喚起 Steam 並等你登入後重試），
再選擇更新 MOD 內容（含 `STEAM_CHANGELOG.md` 更新說明）／GIF 封面／簡介／全部；提交後回查 Steam，
任一不符即以非零碼結束。設定在 `scripts/workshop_publish.json`（Workshop ID、簡介語言槽來源、GIF 路徑）。

```
uv run --no-project python -B scripts/publish_workshop.py --mode all --yes       # 自動化／AI；或 content / preview / description
uv run --no-project python -B scripts/publish_workshop.py --mode all --dry-run   # 只檢查、顯示計畫
```

退出碼：`0` 成功／`2` 參數或取消／`3` 未登入、帳號不是擁有者／`4` 前置檢查失敗／`5` 提交失敗／`6` 已提交但回查不符。
網頁動態封面放 `MOD/<資料夾>/workshop/preview.gif`（不在 `Contents/`，不會下載給玩家）；遊戲內上傳器仍用 `preview.png`，
且每次會把網頁封面覆回靜態，需要動態封面時一律改用本工具發布。
